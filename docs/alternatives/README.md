# Two alternative games

These are independent design prototypes, not revisions to [Trick's current rules](../../RULES.md). Each retains a persistent, customizable character deck. Their resolution, injuries, and advancement stand on their own; do not import Trick's trump, consolations, evolution, or survival rules.

| | [Joinery](JOINERY.md) | [Undertow](UNDERTOW.md) |
| --- | --- | --- |
| Main question | How do our cards fit together? | How far can I push before banking? |
| Resolution | Build exact-total projects in a shared tableau | Reveal from your own deck; repeated ordinary ranks bust |
| Player control | Choose a card and project from a five-card hand | Choose whether to bank, push, or abandon your run |
| Cooperation | Contribute pieces to the same project | Bank separate runs toward the same goal |
| Low cards | Precision pieces that finish a project without overshooting | Rank diversity that makes longer runs possible |
| High cards | Fast progress, but awkward near the target | More progress per draw, but repeated high ranks are dangerous |
| Injury | Visible wounds lock cards outside the deck | Wounds enter the deck and make future pushes dangerous |
| Deck identity | Useful combinations, suit access, and reliable finishing pieces | Rank distribution, suit access, and tolerance for risk |
| Pace | Four simultaneous beats by default | One run each, up to six pushes |

Both can be tested with the existing 21-card starter: 3, 5, 7 of every suit; add A, 3, 5, 7, 9 of a primary suit and 2, 4, 6, 8 of a different secondary suit. This controls the starting materials while comparing completely different play. Neither game requires this exact recipe after the initial test.

**Start with Joinery** if the priority is collective problem-solving and expressing the scene through played cards. **Start with Undertow** if the priority is speed, suspense, and having the deck's composition directly determine risk.

Both are unplaytested. The worked examples have been checked for arithmetic and component availability; numerical difficulty and injury pacing are starting proposals.
