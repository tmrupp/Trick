# Historical designs

These files preserve earlier proposals and card text. They are not current rules.

Use [the player guide](../../PLAYER_GUIDE.md) or [the full rules](../../RULES.md).

`before_player_guide/` preserves the HTML references, card/gallery copy, setting mechanics, and item catalog before their migration to group checks and standard decks. Divine and Blessed are archived expansion concepts; their images are not part of the current exports. Historical pages may refer to obsolete mechanics.
